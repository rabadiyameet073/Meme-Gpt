# MemeGPT Web Application (Vite SPA)

The main web application — ChatGPT-style meme search interface.

## Tech Stack
- React 19 + TypeScript
- Vite 6
- Framer Motion
- Lucide React icons

## Run locally
```bash
npm install
npm run dev  # http://localhost:5173
```

## Deploy
Deployed to Vercel as `app.memegpt.com`
