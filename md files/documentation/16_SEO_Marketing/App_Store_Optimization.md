## Rating Strategy

| Timing | Prompt | Goal |
|---|---|---|
| After 3rd successful search | "Enjoying MemeGPT? Rate us!" | First impression ratings |
| After 5th download | "You've downloaded 5 memes! Rate us?" | Engaged user ratings |
| After share | "Thanks for sharing! Rate us?" | Viral user ratings |

**Rules:**
- Never prompt on first use
- Never prompt after an error
- Max 1 prompt per 30 days
- Always offer "Not now" option

---

## Best Practices

1. **App name includes primary keyword** — "MemeGPT – AI Meme Finder"
2. **First line of description is critical** — users see only 2 lines before "more"
3. **Screenshots tell a story** — show the full user journey
4. **Localize for top markets** — English, Hindi, Spanish, Portuguese
5. **Update screenshots with every major release** — stale screenshots = lower downloads
6. **Respond to all reviews** — especially negative ones (shows you care)
