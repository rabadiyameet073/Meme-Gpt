# MemeGPT — User Personas

> **Document Version:** 2.0 · **Last Updated:** 2026-08-02

---

## Purpose

Detailed user personas representing MemeGPT's target audience — demographics, behaviors, pain points, and how MemeGPT solves their needs.

---

## Persona 1: "Meme Mike" (Primary — Social Chatter)

| Attribute | Details |
|---|---|
| **Age** | 18–28 |
| **Occupation** | College student / Early career |
| **Platforms** | WhatsApp, Instagram, Discord, Twitter/X |
| **Meme usage** | 5–10 memes per day in group chats |
| **Current tools** | Google Images, Giphy, saved meme folder |
| **Pain point** | "I know the meme I want but can't find it by keywords" |
| **Need** | Type a situation → get the perfect meme instantly |
| **Format preference** | GIF (for chat), PNG (for Instagram) |
| **Device** | Mobile (70%), Desktop (30%) |
| **Willingness to pay** | $0 (free tier, might share for referral) |

### Journey

```
1. Friend says something funny in WhatsApp group
2. Thinks "there's a perfect meme for this"
3. Opens MemeGPT → types "when your friend says they'll be ready in 5 min"
4. Gets 5 perfect meme suggestions in 2 seconds
5. Taps "Copy" → pastes in WhatsApp → sends
6. Group chat erupts with 😂 reactions
7. Tells 3 friends about MemeGPT
```

## Persona 2: "Developer Dave" (Secondary — Tech Worker)

| Attribute | Details |
|---|---|
| **Age** | 22–35 |
| **Occupation** | Software developer |
| **Platforms** | Slack, Discord, GitHub, Twitter/X |
| **Meme usage** | 3–5 memes per day in Slack channels |
| **Current tools** | Bookmark folders, Giphy Slack integration |
| **Pain point** | "Giphy's results are irrelevant and full of ads" |
| **Need** | Quick, relevant tech memes for Slack |
| **Format preference** | GIF (for Slack) |
| **Device** | Desktop (80%), Mobile (20%) |
| **Willingness to pay** | $9/mo for API access |

## Persona 3: "Creator Chloe" (Tertiary — Content Creator)

| Attribute | Details |
|---|---|
| **Age** | 20–30 |
| **Occupation** | Social media manager / Influencer |
| **Platforms** | Instagram, TikTok, Twitter/X |
| **Meme usage** | 10+ memes per day for content creation |
| **Current tools** | Know Your Meme, Reddit, Pinterest |
| **Pain point** | "Finding trending, high-quality memes takes too long" |
| **Need** | Trending memes + multiple format options |
| **Format preference** | PNG (for posts), MP4 (for Reels/TikTok) |
| **Device** | Desktop (60%), Mobile (40%) |
| **Willingness to pay** | $9/mo for unlimited, no watermarks |
